Tapping a link only downloads the file. Nothing installs until you open it from Quetta's Extensions page.

Install in Quetta (Android)

  1. Tap Download .crx above. If Quetta won't download it, long-press the button and choose Download link.
  2. Open Quetta's menu (⋮) → Extensions. You can also type chrome://extensions in the address bar.
  3. Turn on Developer mode.
  4. Tap the button that installs from a file (it may say + (from .zip/.crx/.user.js), Load or Install from file) and pick the file from Downloads.
  5. If the .crx is refused, try again with the .zip.
  6. Check that the installed id matches the id at the top of this page.

On a computer (development only)

Desktop Chrome downloads the .crx but won't install extensions from outside the Web Store. For development, unzip the .zip and use chrome://extensions → Developer mode → Load unpacked.
