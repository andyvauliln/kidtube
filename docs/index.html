Install in Quetta (Android)

  1. Tap Download .crx above. If Quetta won't download it, long-press the button and choose Download link.
  2. Open Quetta's menu (⋮) → Extensions. You can also type chrome://extensions in the address bar.
  3. Turn on Developer mode.
  4. Tap the button that installs from a file (it may say + (from .zip/.crx/.user.js), Load or Install from file) and pick the file from Downloads.
  5. If the .crx is refused, try again with the .zip.
  6. Check that the installed id matches the id at the top of this page.

Install in Orion (iPad, iPhone or Mac)

  1. In Orion open Settings → Extensions and turn on Chrome extensions.
  2. Tap Download .zip above and save it to Files (iPad/iPhone) or Downloads (Mac).
  3. Open Orion's Extensions list, tap + and choose the file-based install, then pick the .zip (if it is refused, try the .crx).
  4. Open the KidTube settings (⚙️ on the kid's screen, or the extension's options) and set the PIN and the GitHub key like on the tablet.
  5. Open youtube.com: you should see his list instead of YouTube.

Differences in Orion:

  • Other websites are sent back to his list by KidTube itself (Orion has no blocking rules), so a page may flash for a moment first.
  • Speech recognition may be missing in Orion on iPad/iPhone. Then he types his answers, unless you choose Hearing his answers → OpenRouter on the parent page.
  • Orion may not update file-installed extensions by itself: when the parent page shows Install the new version, download the new .zip here and install it again.
  • Use Screen Time on the iPad to keep him in Orion (and out of Safari and the YouTube app).

On a computer (development only)

Desktop Chrome downloads the .crx but won't install extensions from outside the Web Store. For development, unzip the .zip and use chrome://extensions → Developer mode → Load unpacked.
